</objective>

1. server/config/runtime-config.ts readRuntimeConfig(mode): cookieSecure (true in production unless LAFU_COOKIE_SECURE is "false" AND LAFU_HOST is a loopback address; always false in development), publicOrigin (LAFU_PUBLIC_ORIGIN optional; when absent the expected origin is derived from the request protocol and Host header), trustProxy (LAFU_TRUST_PROXY "1" enables app.set trust proxy 1). server/app.ts applies trustProxy and mounts app.use("/api/admin", createAdminRouter({ prisma, config })) before the /api 404 handler.

2. server/auth/password.ts (per D-15): hashPassword(plain) uses crypto.scrypt with N 131072, r 8, p 1, keylen 64, maxmem 256 MiB, random 16-byte salt; stored format "scrypt$131072$8$1$<salt b64>$<hash b64>". verifyPassword(plain, stored) parses the format and compares with crypto.timingSafeEqual. verifyAgainstDummy(plain) runs the same scrypt against a module-level dummy hash so unknown emails cost the same time.

3. server/auth/provisioning.ts (per D-14): provisionAdmin(prisma, { email, displayName, password }) trims and lowercases email, validates email shape, displayName 1..120 chars, password 12..256 chars; creates the account or, when it exists, replaces passwordHash, sets passwordUpdatedAt and isActive true, and revokes every AdminSession of that admin (sets revokedAt); returns "created" or "updated". deactivateAdmin(prisma, email) sets isActive false and revokes sessions. scripts/admin-provision.ts parses --email, --name, --password-stdin, --deactivate; without --password-stdin it prompts twice with echo disabled (readline with muted output) and requires both entries to match; it prints only the outcome word and the email, never the password, and exits 1 with a message on invalid input. package.json adds script "admin:provision": "tsx scripts/admin-provision.ts". The database file comes from resolveDatabaseFile.

4. server/auth/cookie.ts: parseCookies(header) (split on ";" and first "="; decode values; ignore malformed pairs) and serializeSessionCookie(token, { secure, expiresAt }) / clearSessionCookie for cookie name lafu_admin with HttpOnly, SameSite=Lax, Path=/, Expires and Max-Age equal to the absolute expiry. server/auth/session-store.ts: createAdminSession(prisma, adminId, now) generates a 32-byte random base64url token and a 32-byte csrfToken, stores sha256(token) hex as tokenHash, expiresAt now plus 14 days, returns { token, csrfToken, expiresAt }; findValidAdminSession(prisma, token, now) looks up by tokenHash and returns null when revoked, expired, or the admin is inactive, and updates lastSeenAt at most once per 5 minutes; revokeAdminSession and revokeAllAdminSessions set revokedAt.
